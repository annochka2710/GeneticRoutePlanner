# Поиск оптимального маршрута с помощью



генетического алгоритма

Демонстрационный код подсистемы автоматизированного планирования воздушного маршрута, разработанной в рамках магистерской ВКР.

Задача — сократить длину маршрута и время его прохождения с учётом обхода препятствий, запретных зон и зон сильного ветра. Для поиска маршрута используется генетический алгоритм с геодезическими расчётами и ограничениями на параметры движения агента.

## Состав

- `GA.hpp`, `GA.cpp` — генетический алгоритм: оценка маршрутов, селекция, скрещивание и мутации.
- `routeplaner.hpp`, `routeplaner.cpp` — управление построением и отображением маршрутов.
- `settings.hpp`, `settings.cpp` — параметры агента и алгоритма.
- `zones.hpp`, `zones.cpp` — работа с зонами ветра.

## Зависимости и статус

Код написан на C++ с использованием Qt и собственных библиотек геодезии, картографического отображения и работы с CSV (`Geodesy`, `GeoItem`, `SPGeoItem`, `GeoGUI`, `FileSystemUtils`). Собственные библиотеки в репозиторий не включены.

Исходники перенесены из приложения А к ВКР для демонстрации подхода и структуры решения. Для собственных библиотек подготовлены [заглушки интерфейсов](stubs/README.md). Не реализованные в заглушках операции выбрасывают `std::logic_error`; для расчётов нужны настоящие библиотеки.

## Сборка

Требуются CMake 3.16+, компилятор C++11 и Qt 5.12+ с модулем Widgets. Используйте комплект Qt, соответствующий компилятору и архитектуре. Qt 6 не поддерживается текущими листингами.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Если Qt не найден, добавьте при настройке `-DCMAKE_PREFIX_PATH="<путь к комплекту Qt 5>"`. Для проверки также Qt-заглушек добавьте `-DGA_CHECK_QT_STUBS=ON`. Для генераторов с несколькими конфигурациями укажите `--config Debug` при сборке и `-C Debug` для CTest.

Без Qt можно собрать и запустить только проверки геодезических заглушек:

```sh
cmake -S . -B build -DGA_BUILD_CORE=OFF
cmake --build build
ctest --test-dir build --output-on-failure
```

Собственные библиотеки подключаются параметрами `GA_USE_LIBRARY_STUBS=OFF`, `GA_PRIVATE_INCLUDE_DIRS` и `GA_PRIVATE_LIBRARIES`; [подробнее](stubs/README.md#подключение-и-замена).

## Статус проекта

CMake собирает `genetic_algorithm` — статическую библиотеку ядра (`GA` и `settings`). В этих файлах исправлены несогласованности переноса из PDF и добавлены отсутствовавшие определения конструктора и проверки хромосомы. Это демонстрационный код, а не подтверждённая реализация оптимального планировщика.

Листинги интерфейса (`routeplaner`, `zones`) доступны в цели `thesis_gui_sources`, но не компилируются: формы, ресурсы и `main.cpp` отсутствуют, в листингах остаются несогласованности. Исполняемый файл приложения не создаётся. Проверки в `stubs/` проверяют заглушки, а не правильность поиска маршрута.

В Git следует хранить исходники, `stubs/`, `cmake/`, `CMakeLists.txt`, README и настройки проекта. Результаты сборки, настройки IDE и локальные данные исключены через `.gitignore`.
