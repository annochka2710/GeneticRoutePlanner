# Поиск оптимального маршрута с помощью



генетического алгоритма

Демонстрационный код подсистемы автоматизированного планирования воздушного маршрута, разработанной в рамках магистерской ВКР.

Задача — сократить длину маршрута и время его прохождения с учётом обхода препятствий, запретных зон и зон сильного ветра. Для поиска маршрута используется генетический алгоритм с геодезическими расчётами и ограничениями на параметры движения агента.

## Состав

- `GA.hpp`, `GA.cpp` — генетический алгоритм: оценка маршрутов, селекция, скрещивание и мутации.
- `routeplaner.hpp`, `routeplaner.cpp` — управление построением и отображением маршрутов.
- `settings.hpp`, `settings.cpp` — параметры агента и алгоритма.
- `zones.hpp`, `zones.cpp` — работа с зонами ветра.

## Зависимости и статус

Код написан на C++ с использованием Qt и собственных библиотек геодезии, картографического отображения и работы с CSV (`Geodesy`, `GeoItem`, `SPGeoItem`, `GeoGUI`, `FileSystemUtils`). Собственные библиотеки в репозиторий не включены.

Исходники перенесены из приложения А к ВКР и опубликованы для демонстрации подхода и структуры решения. Это не самостоятельное готовое к сборке приложение: в текущей версии отсутствуют заглушки собственных библиотек, формы интерфейса и файлы сборки.
