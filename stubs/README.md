# Заглушки собственных библиотек

Здесь описана только часть интерфейсов собственных библиотек, используемая в приложении А к ВКР. Сигнатуры восстановлены по обращениям в листингах; это не копия исходных библиотек и не гарантия совместимости с их SDK.

| Подключение в исходниках | Что представлено |
| --- | --- |
| `Geodesy/Math/PZ_90` | Координаты и углы, преобразование представления 2D/3D |
| `Geodesy/Math/Ellipsoid` | Интерфейс ортодромии: длина, точки, прямая задача |
| `Geodesy/Math/GnomonicPoint` | Интерфейсы гномонической проекции и вычисления угла |
| `Geodesy/Math/Spheroid` | Интерфейс пересечения географических полигонов |
| `GeoItem/AllItems`, `SPGeoItem/Polygon` | Географические значки, подписи, полигоны и операции карты |
| `GeoGUI/GeoCoordView` | Интерфейс форматирования координат |
| `FileSystemUtils/CSVFile` | Интерфейс чтения и перебора строк CSV |

## Поведение

Реализованы хранение данных, работа с углами в радианах, базовая проверка координат и копирование полигона. `to3d()` добавляет нулевую высоту, `to2d()` отбрасывает высоту; преобразований между геодезическими системами нет.

Геодезические расчёты, пересечение зон, отрисовка, форматирование координат, сериализация и чтение CSV **не реализованы**. Вызов этих операций выбрасывает `std::logic_error` с сообщением `Demo stub: <операция>`. Заглушки предназначены для представления зависимостей в демонстрационном коде. Для запуска расчётов нужны реальные реализации; необработанное исключение останавливает программу.

Публичные заголовки в `include/` сохраняют пути исходных `#include`. Реализации заглушек сосредоточены в `include/demo_stubs/`. Qt остаётся настоящей внешней зависимостью и не подменяется.

## Подключение и замена

Файл `cmake/ProjectDependencies.cmake` в корне репозитория создаёт цель `GeneticAlgorithm::Dependencies`. Корневой `CMakeLists.txt` уже подключает её к библиотеке `genetic_algorithm`. Для другой цели используется тот же способ:

```cmake
include(cmake/ProjectDependencies.cmake)
target_link_libraries(my_application PRIVATE GeneticAlgorithm::Dependencies)
```

`my_application` — имя другой цели. Этот пример не добавляет GUI-приложение. По умолчанию `GA_USE_LIBRARY_STUBS=ON`: добавляются заголовки из `stubs/include`, определяется `GA_LIBRARY_STUBS=1`.

Чтобы подключить собственные библиотеки, при настройке сборки приложения укажите:

```text
-DGA_USE_LIBRARY_STUBS=OFF
-DGA_PRIVATE_INCLUDE_DIRS=C:/SDK/include
-DGA_PRIVATE_LIBRARIES=C:/SDK/lib/Geodesy.lib;C:/SDK/lib/GeoItem.lib
```

Пути и список библиотек замените на реальные; список через `;` передавайте одним аргументом в кавычках. Можно указать имена импортированных целей CMake вместо файлов библиотек. В этом режиме путь `stubs/include` не подключается. При совпадении интерфейсов менять исходные `#include` не требуется; отличия SDK исправляются в месте интеграции.

Без CMake добавьте `stubs/include` в пути поиска заголовков. При замене библиотек удалите этот путь и добавьте пути SDK, чтобы заглушки не перекрывали настоящие заголовки.

## Проверка заглушек

Проверка геодезических заголовков не требует Qt:

```sh
cmake -S stubs -B build/stubs
cmake --build build/stubs
ctest --test-dir build/stubs --output-on-failure
```

С установленным Qt 5.12 или новее можно также проверить интерфейсы карты, CSV и GeoGUI:

```sh
cmake -S stubs -B build/stubs -DGA_CHECK_QT_STUBS=ON
cmake --build build/stubs
ctest --test-dir build/stubs --output-on-failure
```

При необходимости задайте `CMAKE_PREFIX_PATH` до комплекта Qt 5. Для генераторов с несколькими конфигурациями используйте `--config Debug` при сборке и `-C Debug` при запуске CTest. Qt-проверка запускается без окна через платформу `offscreen`. Qt 6 не заявлен: листинги используют API Qt 5 (`QTextCodec`, `QSettings::setIniCodec`).

## Ограничения исходников

Заглушки не восстанавливают GUI-листинги из PDF. В `routeplaner` и `zones` остаются разорванные строки, повторные объявления, несовпадения типов и путей `src/...`. Ядро `GA` и `settings` отдельно подготовлено к сборке в корневом CMakeLists.txt. Формы `ui_routeplaner.h`, `ui_zones.h`, ресурсы и точка входа отсутствуют.

Типы `Ics::SP::QPolygon`, `Ics::SP::QIcon`, `Ics::SP::QLabel` — элементы собственных библиотек. При подключении Qt их нужно указывать с полным пространством имён, чтобы исключить неоднозначность с одноимёнными классами Qt. Все восемь исходников вместе не собираются: корневой проект собирает ядро, а проверки выше относятся только к заглушкам.
